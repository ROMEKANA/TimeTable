# TimeTable

塾の時間割、生徒・講師情報、予定表、給与明細、指導報告書などを管理・印刷するQtデスクトップアプリです。

## 開発環境

- Windows
- Qt 6.11.0
- MinGW 13.1.0 64-bit
- CMake
- C++17

Qtの主なパスは次の場所を前提にしています。

```text
C:\Qt\6.11.0\mingw_64
C:\Qt\Tools\mingw1310_64
C:\Qt\Tools\CMake_64
```

プロジェクト本体：

```text
C:\Users\TO\Documents\jukuTimeTable\TimeTable
```

## 主なファイル

- `mainwindow.cpp` / `mainwindow.h`：メイン画面、共通処理
- `settingsdialog.cpp` / `settingsdialog.h` / `settingsdialog.ui`：統合設定画面
- `scheduleTab.cpp`：時間割
- `scheduleData.cpp`：時間割データの変換
- `scheduleStorage.cpp`：時間割の読み書き
- `studentTab.cpp`：生徒
- `teacherTab.cpp`：講師
- `exportTab.cpp`：印刷、PDF、予定表、給与明細、指導報告書
- `undo.cpp`：元に戻す・やり直し
- `updaterMain.cpp`：GitHub Releasesからの自動更新
- `make-release-zip.bat`：配布用ZIPの作成
- `AGENTS.md`：Codex向けの作業ルールと既知の注意点

## データ保全

### 保存とバックアップ（v0.3.29以降）

- 時間割・マスター設定・生徒・講師・学校・終了時の画面状態は、一時ファイルへの全量書き込みに成功してから置き換えます。読み込みに失敗したファイル、読み込み後に外部で変更・削除されたファイルは上書きしません。
- これらのファイルを読み込む前に、実行ファイルの隣の `backups/YYYY-MM-DD/` へ元の配置を保ってコピーします。同日のコピーは更新しますが、`versions/` に内容別の旧世代も保持します。世代名の末尾は内容のハッシュです。同じ内容は同じ世代として扱います。
- 上書き前のファイルと、授業を削除する構造変更・週コピー前の未保存時間割も世代バックアップへ退避します。バックアップに失敗した操作は中止します。自動削除・世代数制限はありません。
- 「ファイル」→「バックアップフォルダーを開く」でエクスプローラーを開けます。復元画面はありません。必要なコピーはアプリを閉じて元の保存先へ戻してください。`versions/` のファイルを戻す場合は元のファイル名に戻します。バックアップは同じディスク上なので、ディスク故障に備える場合はこのフォルダーを別の保存先へもコピーしてください。
- 外部から開いた `.schedule` は、開いた元のファイルへ保存します。通常の週切り替えは従来どおり `schedules/` を使います。「来週へコピー」は表示中の週の翌週が対象で、既存ファイルへの上書きは保存先を表示して確認します。
- 不正な貼り付け、破損JSON、対応外バージョン、配列数や型が不整合なデータは取り込みません。現在の最大生徒数を超える位置に授業がある時間割も切り捨てずに読込を中止するため、人数設定を増やしてから読み直してください。
- 曜日は日付との対応を保つため月から日の順で途中を省略できません。時限は名前を照合して授業を移します。時限の名前変更は旧時限の削除と新時限の追加として扱います。人数・曜日・時限の縮小と講師列の削除では、削除件数の確認とバックアップを行います。
- 同じ学年の同名生徒・同名講師の登録と読込は拒否します。既存データを区別できる名前に直してから読み込んでください。使用中の性別マスターの削除・並べ替え・名前変更も、既存生徒の意味が変わるため拒否します。
- PDF出力は一時PDFを検証してから既存PDFを退避・置換します。指導報告書の分割中に名前変更が失敗した場合は、それまでの出力を作業フォルダーへ戻します。戻せなかったファイルは場所を表示して残すため、再実行前に確認してください。
- 自動更新は保存確認がキャンセルされた場合など、アプリが終了しなければ中止します。更新アプリのファイルは一時フォルダーの `original-app/` へ退避し、失敗時に戻します。復旧失敗時は `update-error.log` に退避先を残します。更新中の異常終了で `.timetable-update.lock` が残った場合は、更新プロセスが終了していることを確認してからこのマーカーファイルを削除してください。

### データ保全の確認

Debugビルドでは `DataIntegrityTests` と `tests/updaterSafetyTests.ps1` をCTestへ登録します。実データやTimeTableの画面を使わず、一時領域で保存・検証・バックアップ・外部変更・更新のロールバックを試験します。

```powershell
$env:PATH='C:\Qt\Tools\mingw1310_64\bin;C:\Qt\6.11.0\mingw_64\bin;' + $env:PATH
& 'C:\Qt\Tools\CMake_64\bin\ctest.exe' --test-dir 'build/Desktop_Qt_6_11_0_MinGW_64_bit-Debug' --output-on-failure
```

実画面での確認にはテスト用データを使ってください。

1. 保存後、「ファイル」からバックアップフォルダーを開き、日別コピーと旧世代を確認する。
2. 授業が入ったセルへ普通の文字・`{}`・型の違うJSONを貼り付け、セルとUndo履歴が変わらないことを確認する。
3. 外部の時間割を開いて保存し、元の場所へ保存されることを確認する。表示中の翌週へのコピーでは保存先と上書き確認を見る。
4. 人数削減・時限の削除/並べ替え・講師列削除で、キャンセル時に元の授業が残り、続行時にバックアップが残ることを確認する。
5. テスト用JSONの破損や外部変更、保存先を書き込めない状態を作り、元ファイル・一覧・入力が残ることを確認する。
6. PDFの名前入力中に日付・講師・PDFを切り替え、キャンセル時の保持を確認する。分割後は生徒・教科・日付・送付先・添付ファイルを照合して送付する。
7. PDF保存失敗の通知、給与対象の破損週/未完成授業での集計中止、自動更新の保存確認キャンセルを確認する。

## バージョン管理

バージョンは `CMakeLists.txt` の次の形式の行で管理します。
以下の `x.y.z` は説明用の表記なので、実際のバージョン番号へ置き換えます。

```cmake
project(TimeTable VERSION x.y.z LANGUAGES CXX)
```

ファイルを変更するときは、バージョンも一緒に更新します。

コミットメッセージは、先頭に変更後のバージョンを入れます。

```text
vx.y.z 変更内容
```

GitHub Releaseのタグも同じバージョンにします。

```text
vx.y.z
```

## Debugビルド

通常の動作確認では、次のDebugビルドだけを実行します。

```powershell
$env:PATH='C:\Qt\Tools\mingw1310_64\bin;C:\Qt\6.11.0\mingw_64\bin;' + $env:PATH
& 'C:\Qt\Tools\CMake_64\bin\cmake.exe' --build 'C:/Users/TO/Documents/jukuTimeTable/TimeTable/build/Desktop_Qt_6_11_0_MinGW_64_bit-Debug' --target all
```

`cc1plus.exe` が `-1073741515` で終了する場合は、上記の2つのQtパスが `PATH` の先頭に入っているか確認します。

## リリース手順

### 1. 変更内容を確認する

- 必要な修正がすべて入っているか確認する
- `CMakeLists.txt` のバージョンを次の番号へ更新する
- Debugビルドが成功することを確認する
- `git status` で意図しないファイルが含まれていないことを確認する

Gitのコミット、タグ、プッシュはユーザーが行います。

### 2. Releaseビルド環境を確認する

Qt Creatorで次のReleaseビルドフォルダが作成済みである必要があります。

```text
build\Desktop_Qt_6_11_0_MinGW_64_bit-Release
```

Release構成がない場合は、Qt Creatorで `Desktop Qt 6.11.0 MinGW 64-bit` のRelease構成を作って、一度ビルドします。

### 3. 配布用ZIPを作る

プロジェクト内の次のファイルをダブルクリックします。

```text
make-release-zip.bat
```

このバッチは次の処理を行います。

1. `TimeTable.exe` と `TimeTableUpdater.exe` をReleaseビルド
2. `windeployqt` で必要なQt DLLとプラグインを配置
3. ビルド用ファイルや利用者データ用フォルダを除外
4. `releases` フォルダへ配布用ZIPを作成

作成されるファイル名：

```text
releases\TimeTable-vx.y.z-win64.zip
```

ZIP名のバージョンは `CMakeLists.txt` から自動取得されます。

### 4. ZIPを確認する

作成したZIPを別の一時フォルダへ展開し、少なくとも次を確認します。

- `TimeTable.exe` が起動する
- `TimeTableUpdater.exe` が入っている
- QtのDLLと `platforms` などの必要なフォルダが入っている
- `qpdf12.3.2\bin\qpdf.exe` とqpdfのDLL一式が入っている
- 開発用ファイルや既存の `data`、`schedules` が入っていない

`data`、`schedules`、`schedulePDF` は利用者の既存データを配布物で上書きしないため、ZIPから除外されます。

### 5. Gitへ反映する

次の内容をユーザーが実行します。

1. 変更をコミット
2. `master` をGitHubへプッシュ
3. バージョンと同じタグを作成
4. タグをGitHubへプッシュ

例：

```text
コミット：vx.y.z 変更内容
タグ：vx.y.z
```

### 6. GitHub Releaseを公開する

GitHubの `ROMEKANA/TimeTable` リポジトリで新しいReleaseを作成します。

- タグ：`vx.y.z`
- Releaseタイトル：`vx.y.z`
- 本文：主な変更内容と注意点
- 添付ファイル：`TimeTable-vx.y.z-win64.zip`

更新アプリは次のGitHub Releases APIから最新版を確認します。

```text
https://api.github.com/repos/ROMEKANA/TimeTable/releases/latest
```

Releaseを下書きのままにせず、公開済みにします。公開後、更新アプリから新しいバージョンとZIPが見つかることを確認します。

## 注意

- `build`、`releases`、実行ファイル、DLL、ZIPはGit管理対象外です。
- `qpdf12.3.2` はGit管理対象外です。指導報告書PDFの分割に必要なため、Releaseビルドフォルダーへ配置し、配布ZIPに含まれていることを毎回確認します。
- `make-release-zip.bat` にはPC固有の絶対パスが設定されています。Qtやプロジェクトの場所を変えた場合は、バッチ先頭のパスも変更します。
- 通常のコード修正確認では、配布用ZIPを作成しません。リリースするときだけバッチを実行します。
- 既知の問題や完成前の確認事項は `AGENTS.md` に記録されています。

## マニュアルの編集・配布

- 初期版は `defaults/manual.md`。実行ファイルには埋め込まず、Debug/Releaseビルド時に実行ファイル横の `defaults` へコピーします。ZIPにもこのフォルダーを含めます。
- 利用者版は実行ファイル横の `data/manual.md`。起動時または「再読み込み」時に存在しない場合だけ初期版からコピーします。既存ファイルはアップデートでも維持するため、初期版の追記は自動では反映されません。
- UTF-8のMarkdownを編集・保存し、「マニュアル → 再読み込み」で反映します。書き方はマニュアル内の「このマニュアルを変更する」を参照してください。
- `# グループ`、`## ページ名 {page-id}`、`### 大見出し`、`#### 小見出し`、`**太字**`、`*赤字*`（本アプリでは斜体を強調色として表示）を使えます。IDは省略可能です。
- スタイルは「設定 → マニュアル」で変更し、既存の `data/master.json` に保存します。
- ファイル読み込みと検索用本文の準備は起動時・再読み込み時だけ行い、選択ページだけ描画します。上限2 MiB。UTF-8不正・重複ID・未完了コードブロックなどの読み込み失敗時は、直前に読み込めた内容を残してエラーを表示します。

確認する操作：初回起動後のファイル生成、内容編集と再読み込み、検索の0件からの復帰、ページ・画面・設定へのリンク、スタイルの保存と再起動後の保持、編集済みファイルが初期版の変更で上書きされないこと。
